Explanation of New Fields
TTP:
Tactic: Maps to MITRE ATT&CK tactic (e.g., "Initial Access").
Technique: Specific technique used (e.g., "Exploit Public-Facing Application").
SubTechnique: Optional sub-technique for granularity (null if not applicable).
TTP_ID: MITRE ATT&CK ID (e.g., "T1190").
Procedure: Brief description of the specific attack method.
Purpose: Links the event to a standardized threat framework for threat intelligence and response.
OWASP_LLMTop10:
RiskID: OWASP Top 10 for LLMs identifier (e.g., "LLM01" for Prompt Injection).
RiskDescription: Brief explanation of the OWASP risk.
Purpose: Aligns the event with LLM-specific risks for better vulnerability management.
NIST_CSF:
Function: NIST CSF function (e.g., "Detect").
Category: Specific category within the function (e.g., "Anomalies and Events").
Purpose: Maps to NIST Cybersecurity Framework for compliance and reporting.
ISO_27001:
ControlID: ISO 27001 control (e.g., "A.12.4.1").
ControlDescription: Description of the control (e.g., "Event Logging").
Purpose: Aligns with ISO 27001 for audit and compliance purposes.
AttackVector:
Specifies the entry point of the attack (e.g., "API").
Purpose: Provides context on how the system was targeted.
UserAgent:
Captures the client’s user agent string (e.g., browser or tool used).
Purpose: Helps identify the source of the request for forensic analysis.
GeoLocation:
Country and City: Derived from SourceIP (placeholder "Unknown" if not resolved).
Purpose: Adds geographic context for threat attribution.
ConfidenceScore:
A value between 0 and 1 indicating the likelihood of a true positive.
Purpose: Assists in prioritizing alerts and reducing false positives.
CorrelationID:
Unique identifier to link related events across systems.
Purpose: Facilitates event correlation in SIEM or analytics platforms.
FrameworkVersion:
Tracks versions of frameworks used (e.g., MITRE ATT&CK v13, OWASP Top 10 for LLMs 2023).
Purpose: Ensures traceability and compatibility with framework updates.
